# Sport 運動狀況統計專案  
_日常運動資料統計_

---

## 專案簡介  
這是一個簡單的運動數據統計與展示專案。  
透過 CSV 格式的運動數據 (`sport.csv`)，結合靜態網頁 (`map_activity.html`、`record.html`)，來展示運動軌跡及詳細記錄。

---

## 檔案說明  
- **sport.csv**  
  運動數據檔案，包含運動過程中記錄的各項指標（如時間、距離、速度等）。

- **map_activity.html**  
  利用地圖視覺化運動路線的網頁。

- **record.html**  
  顯示運動數據詳細列表及統計的網頁。

---

## 使用說明  
直接用瀏覽器開啟 `map_activity.html` 或 `record.html`，即可看到運動數據的可視化與統計。

---

## 注意事項  
- 確保 `sport.csv` 格式正確且與目前結構一致。  
- `map_activity.html` 可能需連網使用第三方地圖服務。
